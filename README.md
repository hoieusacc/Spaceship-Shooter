## Overview

Spaceship-Shooter is a foundational game development project that combines core gameplay mechanics with modern C++ data handling and cross-platform multimedia support. It serves as an excellent starting point for developers interested in building interactive games or multimedia applications.

### Why Spaceship-Shooter?

This project aims to demonstrate essential game features, JSON data management, and portable graphics rendering within a clean architecture. The core features include:

- 🎮 **Game Mechanics**: Implements a basic game loop with player movement, shooting, enemy spawning, and scoring.
- 📝 **JSON Handling**: Utilizes the nlohmann/json library for serialization, deserialization, and custom data serialization.
- 🖥️ **Cross-Platform Graphics**: Supports SDL2, OpenGL ES, and EGL for portable rendering across diverse systems.
- 🛠️ **Developer Tools**: Includes debugging, testing frameworks, and resource management for efficient development.
- 🎨 **Multimedia Integration**: Manages audio, graphics, and input seamlessly within a modular architecture.
